# Claude Code Prompts - Copy/Paste In Order

Use these prompts inside Claude Code. Keep the files CLAUDE.md, IMPLEMENTATION_SPEC.txt, STRATEGY_PLAYBOOK.txt, and strategy_configs.json in the project folder.

============================================================
PROMPT 0 - PLAN FIRST
============================================================

Read CLAUDE.md, IMPLEMENTATION_SPEC.txt, STRATEGY_PLAYBOOK.txt, and strategy_configs.json.
Do not start coding yet.

First produce a concise implementation plan with:
1. repository structure
2. core modules/classes
3. data assumptions
4. which strategies you will implement first
5. tests you will write first
6. simplifications you will make in v1
7. risks that remain unresolved

Be conservative. This is a research/backtesting bot, not a live trading bot.

============================================================
PROMPT 1 - CREATE PROJECT SKELETON
============================================================

Now create the Python project skeleton exactly according to IMPLEMENTATION_SPEC.txt.

Create:
- src/quantbot package
- data, indicators, strategies, portfolio, risk, costs, backtest, options, reporting, utils modules
- configs folder
- tests folder
- README.md
- requirements.txt or pyproject.toml

Do not implement every strategy yet. Create clean placeholders and base classes. Add docstrings explaining what each module is responsible for.

============================================================
PROMPT 2 - DATA VALIDATION AND COST MODEL
============================================================

Implement the data validation and transaction cost modules first.

Build:
1. OHLCV validator
2. options chain validator placeholder
3. futures chain validator placeholder
4. transaction cost model for equities/ETFs
5. transaction cost model for options structures
6. unit tests for validators and costs

Make sure missing values are handled explicitly and never silently converted to zero.

============================================================
PROMPT 3 - BACKTEST ENGINE V1
============================================================

Implement BacktestEngine v1.

Requirements:
- no look-ahead bias
- strategy generates signals using data up to date t
- execution happens on next bar according to config
- simulate cash, positions, equity curve, orders, fills, and transaction costs
- support target weights
- output performance metrics
- include tests proving transaction costs reduce returns and signals are not executed before they exist

Keep it simple and robust.
